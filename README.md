# GUESSING-GAME
Created a simple game that generates a random number and takes user guesses until the correct one is found.

After each guess, the program gives a hint:
"Too high!" — if your guess is greater than the secret number
"Too low!" — if your guess is smaller than the secret number

The game continues until the player correctly guesses the number.
It also counts how many attempts you took to find the correct answer.

**Concepts Used:**
-Random number generation using rand() and srand()
-Seeding with current time using time(0)
-Conditional statements (if, else if, else)
-Loops (do...while)
-Basic input/output (printf/scanf in C)

**Features:**
-Simple and easy to understand for beginners
-Random number every time you play
-Hints after each guess
-Shows the total number of attempts
